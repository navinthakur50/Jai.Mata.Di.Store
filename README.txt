JAI MATA DI STORE - STARTER WEBSITE

Files:
- index.html: Website content
- style.css: Website design and mobile responsiveness
- script.js: Mobile menu and current year

HOW TO PREVIEW:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

BEFORE PUBLISHING:
1. In index.html, replace the placeholder address.
2. Replace the placeholder phone number in the contact section.
3. Update store timings.
4. Confirm the actual products/categories with the shop owner.
5. Add real shop/product photos only with permission.
6. Check all details with the shop owner before publishing.

This is a static starter website. It does not currently include online payments, inventory, login, or online ordering.
